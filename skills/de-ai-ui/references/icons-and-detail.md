# 图标与多模式素材 / Icons & per-mode assets

## 1. 图标风格统一 — yanliudreamer

来源：<https://x.com/yanliudreamer/status/2113188741452103685>

- 很多产品看起来不够精致，不是布局出了大问题，而是**图标的线条粗细、圆角、比例和视觉重量不统一**。
- 找图标时，除了含义，还要比较线条粗细、填充方式、视觉重量和风格。
- 做整套产品界面时，尽量选择**同一个风格体系**，不要从不同地方拼凑。
- 资源：[The Noun Project](https://thenounproject.com/)。

`[通用实践]` 落到代码里：整个项目只引一个图标库（例如 Kubai087 在空状态示例里用的、@remixdesigner 维护的 [Remix Icon](https://remixicon.com/)，或 Lucide 等），统一 `size`、`stroke-width`，同一界面不混用线性与面性（除非用来表达选中态）。

## 2. 不同外观模式要单独处理素材 — remixdesigner

来源：<https://x.com/remixdesigner/status/2100082157184229741>

- 苹果新版 Preview 图标给 **Clear 模式单独添加了图层**（"Preview Image Clear" 与 "Preview Image Clear Texture"），在默认模式下这些图层不透明度为 0。
- 作者的对比图：把默认模式图片直接转换成 Clear 模式——"有点脏"；为 Clear 模式单独处理图层——"很干净"。

**本 Skill 的引申规则**（属于本仓库的总结，非作者原话）：
- 深色模式、Clear / 着色（tinted）图标、高对比模式下，插画、图标、品牌图要有专门版本或专门图层，而不是 `filter: invert()` / 降饱和一把梭。
- 呼应 ianneo_ai 点评的案例：界面跟着内容"天黑"，而不是硬切深色模式。

## 3. 改造 AI 生成的图标：降低非必要的体积表现 — Kubai087

来源：<https://x.com/Kubai087/status/2115674219602452656>（作者注明案例来自 @H_Stepania_）

AI 容易把简单符号或卡通化的设计放进严谨的空间和物理结构里去理解。改造原则（可直接作为给 AI 的要求）：

1. 主体：非必要不使用过多高光、阴影笔触，尽量用简单的线性或径向渐变构建主体。
2. 主体：非必要尽量让环境光影响主体。（原文如此）
3. 背景：考虑不同圆角下的裁切适配，避免多余的弥散光和材质；用纯粹的线性渐变，色值取同色相不同亮度，或不同色相但鲜亮的颜色。
4. 全局：尽量不要用内发光、内阴影来体现质感，除非明确要求。
5. 全局：高光不要只加亮（会变灰）；阴影用相近色相、更深一点的颜色，不要直接掺黑。

最后让 AI 导出分层 PNG 和背景参数，导入 Icon Composer 适配液态玻璃。——这与第 2 节"分层、分模式处理"是同一个思路。
