# AI slop 自查清单 / Self-audit checklist

交付前逐项检查。命中任何一项 = 需要修。括号内为出处，详见 [`sources.md`](sources.md)。

## A. dingyi 的 19 条 AI slop 典型特征（原清单，按原顺序）

来源：<https://x.com/dingyi/status/2115790005423734818>

- [ ] 1. 到处都是标签和斜体字
- [ ] 2. 三大 slop 字体：Instrument Serif（莫奈风格）、Space Grotesk、Bricolage Grotesque
- [ ] 3. 滥用等宽字体
- [ ] 4. 细节多到过头：分割线、多层阴影、半透明叠色、带边框的容器
- [ ] 5. 图表总是弄得超详细
- [ ] 6. 文案口语化严重，或者自己造词
- [ ] 7. 代码面包屑、章节编号、标题上方的小眉标
- [ ] 8. 紫色渐变
- [ ] 9. 全大写的小标题
- [ ] 10. 用中圆点当分隔符
- [ ] 11. 正文塞 Emoji，到处堆没用的文字
- [ ] 12. hero 区域字体大得离谱
- [ ] 13. 加一堆解释性的描述文字，画蛇添足
- [ ] 14. 嵌套的地方没做同心圆角
- [ ] 15. 线条和边框粗细不统一，该用 0.5px 的地方用了 1px
- [ ] 16. 页面滚动时动效过多，过渡不收敛、很生硬
- [ ] 17. 字号超过 4 种，最小还低于 12px
- [ ] 18. 喜欢在卡片左边缘生成彩色竖线
- [ ] 19. 下拉菜单按钮的下拉小图标（作者认为"最严重"、几乎没人修；原帖配图是一个"过去 30 天"下拉框）

> 第 19 条怎么修，原帖没有给出具体做法。`[通用实践]` 建议至少检查：箭头是否是系统默认样式或与图标库风格不一致、尺寸与字号是否匹配、与文字和右边缘的间距是否与左侧 padding 协调、是否光学居中、展开时是否有状态变化。

## B. 其他来源补充的特征

- [ ] 紫蓝渐变、全部居中排版、卡片套卡片、每个标题上面顶一个 emoji 图标（Xian0063）
- [ ] 编造的数据或社会证明（如"10,000+ 满意客户"）、标题上的英文小标签、单独染色的一个字、结尾硬塞的订阅框（Xian0063 转述 Hallmark 的拦截项）
- [ ] 渐变按钮、彩色图标、一张卡片一个颜色——界面 chrome 抢了内容的颜色（ianneo_ai）
- [ ] 颜色不是成套 token，而是随手写的 hex（ZaynHao：换成 Radix Colors）
- [ ] 没做光学对齐（ZaynHao）
- [ ] 随意的圆角与阴影，数值与功能场景不符（ZaynHao）
- [ ] 需要用户停下来判断的交互太多，或出现在用户没打算做选择的地方（ZaynHao）
- [ ] 多余的文案、分割线和图标（yanliudreamer 转述的英文文章）
- [ ] 图标来自不同风格体系，线条粗细、圆角、比例、视觉重量不统一（yanliudreamer）
- [ ] 深色 / 夜间 / 透明等模式只是把默认素材自动转换，显得"脏"（remixdesigner、ianneo_ai）
- [ ] 中文页面 font-family 中文字体写在西文前面、只写中文名、带空格的名字没加引号、没有 sans-serif 兜底（ricouii）
- [ ] 圆角不在 4px 网格、同层不一致、小于 4px、或 pill 没有全圆（Kubai087）

## C. 输出格式（给 AI 的要求）

自查后按下面格式汇报，然后按严重程度从高到低、每轮只改一处（Xian0063 原则 5）：

```text
命中 N 项：
1. [严重] #19 下拉箭头：默认系统箭头，贴右边缘 4px → 改为图标库 chevron 16px，右 padding 与左 padding 一致
2. [中] #15 边框：.card 1px → 0.5px（低分屏回退见 radius-and-borders.md）
...
```
