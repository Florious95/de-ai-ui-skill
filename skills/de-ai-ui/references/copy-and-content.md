# 文案与内容 / Copy & content

AI 界面露馅，很多时候不是视觉，而是字。

## 规则

| 规则 | 出处 |
| --- | --- |
| 不要使用中点 "·" 作为文案分隔符；如果有，移除它 | ZaynHao 第 1 条；dingyi |
| 不要在界面添加冗余的解释性描述文本——会弄脏界面、浪费用户注意力 | ZaynHao 第 2 条；dingyi（"画蛇添足"） |
| 文案符合目标人群：易懂但不过于口语化，长短适合功能场景，不冗余、不随意造词 | ZaynHao 第 3 条；dingyi（"口语化严重，或者自己造词"） |
| 正文不塞 Emoji，不堆没用的文字；标题上方不顶 emoji 图标 | dingyi；Xian0063 |
| 不要到处都是标签（tag / badge） | dingyi |
| 图表不要做得超详细 | dingyi |
| 不编造数据和社会证明（如"10,000+ 满意客户"）；不在结尾硬塞订阅框；不在标题上加英文小标签 | Xian0063 转述 Hallmark 的拦截项 |
| AI Agent 总喜欢添加多余的文案、分割线和图标——每个元素都要问"真的有存在的必要吗？" | yanliudreamer 转述英文文章 |

## CTA 文案 — yanliudreamer

研究 [CTA Gallery](https://www.cta.gallery/)：对比相似产品的按钮——文案是在描述操作还是强调用户收益？主次按钮层级是否清晰？出现在用户旅程哪个阶段？如何降低犹豫？（<https://x.com/yanliudreamer/status/2113188741452103685>）

## 给 AI 的提示词

```text
Review 这个界面的全部文案：
- 删除所有 "·" 分隔符，改用间距、换行或布局分组；
- 删除冗余的解释性描述；一个控件能自解释就不要配说明；
- 改写成适合【目标用户】的语气：易懂、不口语化、不造新词，长度匹配场景；
- 移除正文和标题里的 Emoji、无意义的标签；不要编造数字或用户评价。
列出每处修改：原文 -> 新文案 / 删除。
```
